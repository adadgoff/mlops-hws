# AGENTS.md — Instructions for AI Agent (Roo Code)

This document provides guidelines for working with the MLOps project.

---

## 1. О проекте

Это распределённая MLOps-система для управления жизненным циклом машинного обучения, включающая:

- **FastAPI backend** (`services/backendrest`) — REST API для управления датасетами, моделями и обучением
- **Streamlit frontend** (`services/frontend`) — веб-интерфейс для взаимодействия с системой
- **Kubernetes** (`kubernetes/`) — манифесты для развёртывания всех компонентов кластера
- **ClearML** — платформа для отслеживания экспериментов ML-моделей
- **DVC** (Data Version Control) — версионирование датасетов и моделей
- **MinIO** — S3-совместимое объектное хранилище для данных и моделей

Система позволяет загружать датасеты, обучать модели с отслеживанием метрик в ClearML, хранить модели в MinIO и выполнять инференс через REST API.

## 2. Правила кода

### Python Style Guide

- **PEP 8** — соблюдайте стандарты стиля Python
- **Type hints** — все функции, методы и переменные должны иметь явные аннотации типов
- **Docstrings** — все публичные модули, классы и функции должны иметь docstrings в формате Google или NumPy

### Pydantic Schemas

- Все входные/выходные данные API должны быть валидированы через **pydantic модели**
- Схемы размещаются в файлах `schemas.py` внутри соответствующих роутов
- Используйте `BaseModel` для определения структур данных

### Общие принципы

- Модульность: каждый компонент (datasets, ml_models, train, inference) должен быть изолирован
- Чистота кода: избегайте дублирования, используйте helper функции
- Обработка ошибок: все исключения должны быть обработаны и возвращены в клиент с понятными сообщениями

```
mlops-hw1/
├── services/
│   ├── backendrest/          # FastAPI REST API сервер
│   │   ├── core/             # Ядро приложения (config, clearml, dvc, minio, ml_models)
│   │   ├── data/             # Локальные данные с .dvc конфигурацией
│   │   ├── ml_models/        # Реализации ML моделей (base, classification, regression)
│   │   ├── routes/           # API роуты (datasets, health, ml/train, ml/inference, ml/crud)
│   │   └── utils/            # Вспомогательные функции
│   ├── frontend/             # Streamlit веб-приложение
│   │   ├── _2_pages/         # Страницы приложения (datasets, inference, ml_models, train)
│   │   ├── _3_widgets/       # Кастомные виджеты (модальные окна, таблицы)
│   │   ├── _4_features/      # Бизнес-логика фронтенда
│   │   └── _5_entities/      # Entity классы для типизации данных
│   └── miniobucketsinitializer/  # Сервис инициализации бакетов MinIO
├── kubernetes/               # Kubernetes манифесты и конфигурации
│   ├── backendrest/          # Deployment backendrest
│   ├── frontend/             # Deployment frontend
│   ├── clearml/              # ClearML развёртывание (helm charts, configs)
│   ├── minio/                # MinIO развёртывание (operator, buckets initializer)
│   └── common/               # Общие ресурсы (namespace)
├── docs/                     # Документация и архитектурные схемы
├── examples/                 # Примеры датасетов для тестирования
└── Makefile                  # Основные команды проекта
```

## 4. Команды для запуска

Используйте [`Makefile`](Makefile) для управления проектом:

| Команда      | Описание                                                                     |
| ------------ | ---------------------------------------------------------------------------- |
| `make run`   | Запуск всех сервисов (backend, frontend, minio, clearml) в режиме разработки |
| `make clear` | Остановка и очистка всех контейнеров Docker                                  |
| `make urls`  | Вывод URL-адресов доступных сервисов после запуска                           |

## 5. Правила для агента

При работе с этим проектом **всегда** выполняйте следующие действия:

1. **Запуск линтеров** — перед коммитом кода всегда запускайте `ruff` для проверки стиля и типов
2. **Написание тестов** — любой новый функционал должен сопровождаться unit/integration тестами
3. **Обновление документации** — изменяйте [`AGENTS.md`](AGENTS.md), [`README.md`](README.md) и другие docs при добавлении новых фич

---

## 6. Запреты

Следующие действия **запрещены** без явного согласования:

- ❌ Изменение существующих API эндпоинтов (путей, методов, форматов ответа) без критической необходимости
- ❌ Нарушение обратной совместимости — все изменения должны сохранять совместимость с клиентами
- ❌ Удаление или модификация рабочих конфигураций Kubernetes без тестирования в staging
- ❌ Изменение схем данных DVC/MinIO без миграционной стратегии
