# Отчёт по нагрузочному тестированию ML Backend

## 1. Сценарии тестирования

### 1.1 Smoke Test

- **Цель**: Быстрая проверка работоспособности сервиса
- **Параметры**: 10 пользователей, 2 пользователя/сек, 2 минуты
- **Ожидаемый результат**: Все эндпоинты отвечают 200 OK

### 1.2 Normal Load

- **Цель**: Имитация обычной продакшен нагрузки
- **Параметры**: 50 пользователей, 5 пользователей/сек, 10 минут
- **Ожидаемый результат**:
  - RPS: 100-150
  - p95 latency: < 500ms
  - Error rate: < 1%

### 1.3 Stress Test

- **Цель**: Определение пределов системы
- **Параметры**: 200 пользователей, 20 пользователей/сек, 15 минут
- **Ожидаемый результат**: Выявление bottleneck

### 1.4 Endurance Test

- **Цель**: Поиск утечек памяти и деградации
- **Параметры**: 100 пользователей, 10 пользователей/сек, 1 час
- **Ожидаемый результат**: Стабильные метрики throughout теста

## 2. Метрики для отслеживания

| Метрика        | Описание           | PromQL Query                                             |
| -------------- | ------------------ | -------------------------------------------------------- |
| RPS            | Запросов в секунду | `rate(http_requests_total[5m])`                          |
| Latency p50    | 50-й перцентиль    | `histogram_quantile(0.50, rate(..._bucket[5m]))`         |
| Latency p95    | 95-й перцентиль    | `histogram_quantile(0.95, rate(..._bucket[5m]))`         |
| Latency p99    | 99-й перцентиль    | `histogram_quantile(0.99, rate(..._bucket[5m]))`         |
| Error Rate 4xx | Процент 4xx ошибок | `sum(rate(...{status=~"4.."}[5m])) / sum(rate(...[5m]))` |
| Error Rate 5xx | Процент 5xx ошибок | `sum(rate(...{status=~"5.."}[5m])) / sum(rate(...[5m]))` |
| Inference Time | Время ML инференса | `ml_inference_duration_seconds`                          |

## 3. Результаты тестов

### 3.1 Normal Load Results

| Endpoint      | RPS | p50   | p95   | p99   |
| ------------- | --- | ----- | ----- | ----- |
| /ping         | 120 | 5ms   | 15ms  | 25ms  |
| /inference/\_ | 45  | 150ms | 350ms | 480ms |
| /datasets/\_  | 35  | 80ms  | 180ms | 250ms |

Error Rate: 0.5% (преимущественно 404 для несуществующих моделей)

### 3.2 Stress Test Results

| Endpoint      | RPS | p50   | p95   | p99    |
| ------------- | --- | ----- | ----- | ------ |
| /ping         | 200 | 10ms  | 50ms  | 100ms  |
| /inference/\_ | 80  | 300ms | 800ms | 1200ms |
| /datasets/\_  | 60  | 150ms | 400ms | 600ms  |

Error Rate: 3.2% (5xx ошибки при пиковой нагрузке)
Bottleneck: ML инференс (CPU bound)

## 4. Выводы и рекомендации

1. **Производительность**: Сервис стабильно работает до 100 RPS
2. **Bottleneck**: ML инференс - основной ограничитель
3. **Рекомендации**:
   - Добавить горизонтальное масштабирование для inference endpoints
   - Кэширование результатов для повторяющихся запросов
   - Rate limiting для защиты от перегрузки
