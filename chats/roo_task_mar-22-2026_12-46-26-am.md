Content: ## О проекте

Это MLOps система, объединяющая FastAPI backend, Streamlit frontend, Kubernetes, ClearML, DVC и MinIO. Система обеспечивает полный цикл разработки и управления ML-моделями, включая разработку, обучение, инференс, хранение данных и модели, а также управление версиями и экспериментами.

## Правила кода

- Стиль кода соответствует PEP 8
- Использование type hints для всех функций и классов
- Все публичные интерфейсы должны иметь docstrings
- Использование pydantic для схем данных и валидации

## Структура проекта

- **services/backendrest** - FastAPI backend с маршрутизацией и сервисами для ML-моделей
- **services/frontend** - Streamlit frontend с визуализацией и интерактивными элементами
- **kubernetes/** - конфигурации для деплоя на Kubernetes, включая backendrest, clearml, minio и мониторинг

## Команды для запуска

- `make run` - запускает backend и frontend
- `make clear` - запускает ClearML для управления экспериментами
- `make urls` - выводит список доступных URL-эндпоинтов

## Правила для агента

- Всегда запускать линтеры (ruff) перед каждым коммитом
- Всегда писать тесты для новых функций и моделей
- Всегда обновлять документацию при изменении API или логики

## Запреты
